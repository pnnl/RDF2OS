# Verification Results

This folder contains all plots and reports generated by the verification workflow.

## Outputs
### Plots
Office Plots: Show how well the simulated mix of occupant types (Manager, Regular Staff, Maintenance, etc.) matches your configured targets in each office space.
Behavior Plots: Show how closely the simulation matches the configured percentage of time each occupant type should spend in different spaces (Own Office, Other Offices, Meeting Rooms, Auxiliary, Outdoor).
Meeting Plots: Show how well the simulation matches your configured meeting behavior — specifically the probability of 30-, 60-, 90-, and 120-minute meetings in each meeting room.

### Excel Data Files
These files are used for generating plots:

Office files: Compare configured vs simulated percentages of each occupant type per office space.
Behavior files: Compare configured vs simulated percentages of time spent in each space category per occupant type.
Meeting files: Compare configured vs simulated values for minimum/maximum meetings per day, minimum/maximum people per meeting, and probability of different meeting lengths per room.

Each Excel file contains three tabs:

Difference – (Simulated – Configured)
Simulated – What the simulation actually produced
Configured – Your target values from the input Excel

## Understanding the Excel data files

### Percent Difference Data Files

- **Difference tab**: Shows (Simulated - Configured)
- **Simulated tab**: Data produced by the simulation
- **Configured tab**: Configured target values from your input file

### Pass/Fail Data Files

- **PassFail tab**: 1 = Pass, 0 = Fail
- **Simulated tab**: Simulated values
- **Configured tab**: Configured target values from your input files

## Understanding the plots

### Plot Interpretation
- **Green** = Simulated result is within 10% threshold or your configured target
- **Red** = Simulated result deviates more than +/-10% from configured target
- Darker colors = larger deviation

The default tolerance is +/- 10 percentage points (use could adjust this in `data_processing.py`).

## Deeper Analysis
In addition to the percent difference and pass/fail outputs, two deeper analysis files are generated in the percent_difference folder for each configuration. These files help explain why a pass/fail result occurred, not just whether it passed:

**behavior_underuse_analysis.xlsx**: When simulated time in a space falls below the configured target, this file identifies where that missing time was redirected instead. Contains a Difference tab (simulated minus configured, for every occupant type and space) and an Underuse_Summary tab listing each underused space alongside the specific spaces that gained time instead.

**meeting_length_bias_analysis.xlsx**: Checks whether the simulation is biased toward longer (120-minute) or shorter (60-minute) meetings compared to what was configured, broken down per meeting room. Shows configured vs. simulated probabilities for both meeting lengths, along with the difference between them.
